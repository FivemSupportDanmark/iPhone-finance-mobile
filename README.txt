Magnus Finance PWA

Filer:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/

VIGTIGT:
PWA-installation og offline-cache virker kun korrekt, når mappen hostes over HTTPS
(fx GitHub Pages, Netlify eller Cloudflare Pages). Den virker ikke fuldt som PWA ved bare at åbne index.html lokalt.

iPhone:
1. Åbn den hostede adresse i Safari.
2. Tryk Del.
3. Vælg Føj til hjemmeskærm.
4. Åbn Magnus Finance fra ikonet.
